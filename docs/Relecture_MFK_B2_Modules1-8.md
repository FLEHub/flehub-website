# Relecture française — Niveau B2, modules 1 à 8

Étape **séparée**, après rédaction des 240 supports et des 2 400 exercices.  
Aucun texte A1, A2 ou B1 n’a été modifié. Les modules restent en brouillon (`published = false`).

## Méthode

1. Génération via `scripts/mfk_b2/generate.py` (5 compétences, 10 types, anagrammes, QCM, SVG, PE *Imitez*).
2. Lecture séquence par séquence : participe composé, futur antérieur, passé simple lu, conditionnel passé, passif, subjonctif d’alternative, discours indirect au passé, double pronominalisation.
3. Contrôle anti-copyright : univers Seuil uniquement (tendances de la cour, archives du Cahier du chemin, Saison des Voix, Lampe-Figue, « le fil » de Radio Figuier, école de la cour). Aucune ville, enseigne, réseau ou titre réel.

Les phrases volontairement fautives des `find_error` restent fautives ; seule la phrase correcte est normative.

---

## Module 1 — Tendances du Seuil

Points : *convainquant* (gérondif) ≠ *convaincant* (adjectif) ; *ayant fini* / *étant partie* ; *quand j’aurai goûté* ; *bien que* + subj. ; *lorsque* / *dès que* / *une fois que*.

Contrôles gardés : futur antérieur (*nous aurons rangé*) ; concession (*néanmoins*, *quoi que*) ; chronique radio inventée.

---

## Module 2 — Mémoire du Seuil

Points : *si j’avais su, j’aurais…* ; passé simple **lu** (*il prit*, *nous vîmes*, *elle relut*) ; *au-delà de*, *en contrebas de*, *à travers*.

Contrôles gardés : le passé simple n’est pas exigé à l’oral de production ; le conditionnel passé pour l’irréel du passé.

---

## Module 3 — Une culture commune

Points : comparatifs / superlatifs de B2 ; *dont* / *auquel* / *duquel* ; *c’est… que* ; *en* / *y* ; registre standard vs familier (*cela* / *c’est pas mal*).

Contrôles gardés : œuvres inventées seulement (*La cour n’oublie pas*, *Le figuier n’oublie pas*).

---

## Module 4 — Vivre avec la technologie

Points : *Faut-il… ?* *Peut-on… ?* ; *in-* / *im-* / *dé-* / *mé-* ; *ça fait… que* ; *relire*, *retracer* ; *or*, *toutefois*, *par conséquent*.

Contrôles gardés : objets inventés (Lampe-Figue, le fil de Radio Figuier) ; pas de marque réelle.

---

## Module 5 — Questions de société

Points : *a été décidé*, *est porté par* ; subjonctif (volonté, doute, sentiment, but, concession) ; *que ce soit… ou…* ; *plutôt que* + subj.

Contrôles gardés : faits « politiques » = assemblée de cour, motion, heures calmes — jamais un parti réel.

---

## Module 6 — Faire évoluer la société

Points : *pourvu que* / *à moins que* + subj. ; *on pourrait* ; *j’aurais dû* ; *quiconque* / *chacun* ; *s’attaquer à* ; *les mesures que nous avons prises*.

Contrôles gardés : accord du PP si COD avant ; conditionnel d’atténuation ≠ futur.

---

## Module 7 — Agir au travail

Points : *il a dit qu’il partirait* ; *elle a demandé si* ; *je le lui ai transmis* ; *il me semble que* ; *encore que* + subj.

Contrôles gardés : postes inventés (atelier, radio, accueil de la cour).

---

## Module 8 — Modèles éducatifs

Points : *qui puisse* ; *il est essentiel que* ; *il est peu probable que* / *il se peut que* ; *ne… ni… ni…*.

Contrôles gardés : chiffres inventés de l’atelier d’Aline ; « école de la cour » uniquement.

---

## Contrôles communs aux 8 modules

- *Il faut* 3e personne ; *je serai* / *je serais* ; *je ferai* (un r) ; *je pourrai* (deux r).
- PE : **Imitez** ; CE / PE lus : *sans aller trop vite*.
- `audio_record` : enregistrement de l’apprenant.
- Anagrammes sans fuite ; aucun jeton virgule ; QCM 4 / 1.
- 30 SVG originaux par module, tous utilisés.
- Supports argumentatifs (12–18 lignes) : articles, interviews, débats, motions, chartes.
- 8 × 30 leçons × 10 exercices = **240 leçons, 2 400 exercices** ; `cefr_level = 'B2'` ; `published = false`.

Aucun dump `*_textes.txt` n’est versionné.
