## Règle de génération (gabarit de leçon)

Pour **chaque séquence**, créer **5 leçons** (une par compétence), dans cet ordre `order_index` :

| `order_index` | `competency` | Compétence | Support dans `content` (`content_type = text`) | Types d’exercices (2 ou 3) |
| --- | --- | --- | --- | --- |
| 0 | `CO` | Compréhension orale | Objectif + consigne + **script d’écoute** (dialogue A1). L’enseignant pourra ensuite remplacer par un audio (`content_type = audio`). | `true_false`, `qcm`, `matching` |
| 1 | `CE` | Compréhension écrite | Objectif + consigne + **texte court** (affiche, fiche, message). | `qcm`, `true_false`, `fill_blank` |
| 2 | `PO` | Production orale | Objectif + consigne + **phrases modèles**. | `matching` ou `word_order`, puis `audio_record` |
| 3 | `PE` | Production écrite | Objectif + consigne + **modèle écrit**. | `fill_blank` ou `word_order`, puis `short_answer` |
| 4 | `EL` | Éléments linguistiques | Objectif + **fiche** (formes + exemples tirés des sous-séquences). | `qcm` / `fill_blank` / `find_error` / `anagram` / `word_order` |

### Colonnes utilisées (aucune table nouvelle)

Il n’existe **pas** de colonne `objectif` / `consigne` / `thème` / `point_de_langue`.

- **Objectif + consigne + support** → `elearning_lessons.content` (`content_type = 'text'`), rendu en `whitespace-pre-wrap`.
- **Titre de leçon** → `elearning_lessons.title`.
- **Thème / point de langue** de la séquence → intégrés dans le texte des leçons EL et dans le titre de séquence.
- **Exercices** → `elearning_exercises.title`, `exercise_type`, `content` (jsonb selon le type).

### Format du champ `content` d’une leçon

```
Objectif
<une phrase CECR A1>

Consigne
<ce que l’apprenant doit faire>

Support
<dialogue, texte, modèle ou fiche>
```
