# Relecture française — Niveau A2, modules 1 à 8

Étape **séparée**, après rédaction des 240 supports et des 2 400 exercices.  
Tous les textes apprenant (objectifs, consignes, dialogues, fiches, items, réponses) ont été relus une seconde fois, module par module. Aucun texte A1 n’a été modifié.

Les modules restent en **brouillon** (`published = false`) : cette passe prépare la relecture humaine avant publication dans l’espace enseignant.

## Méthode

1. Génération des seeds via `scripts/mfk_a2/generate.py` (validation automatique : 5 compétences, 10 types, anagrammes, QCM, SVG utilisés, consignes PE *Imitez*).
2. Lecture séquence par séquence des supports et des `find_error` : grammaire A2 de **la** séquence, accords, *il faut* (toujours 3e personne), futurs / conditionnels, subjonctif.
3. Correction à la source (`scripts/mfk_a2/m1.py` … `m8.py`), puis régénération des 8 fichiers SQL.
4. Contrôle anti-copyright : univers Seuil des Sources uniquement ; Val-des-Peupliers, Bureau des Escales, Maison des Vents, Radio Figuier, Cahier des racines, livre inventé *Le figuier n’oublie pas* — aucune ville, enseigne, émission ou titre réel.

Les phrases **volontairement fautives** des exercices `find_error` restent fautives ; seule la colonne « phrase correcte » est normative. Aucun commentaire méta du type « (Léa parle) » / « au féminin » / « accord avec nous » dans la phrase à corriger.

## Module 1 — Escale en France

Points surveillés : comparatifs (`meilleur`, pas *plus bon*) ; `y` / `en` et élision `j'y` ; ordre `le lui` ; `devoir` / `il faut` + infinitif ; locutions `au-dessus`, `au milieu` ; relatifs `qui` / `que` / `à qui` / `avec qui`.

| Lieu | Avant | Après |
| --- | --- | --- |
| S2 PE — modèle et erreur | *N'y oubliez pas le tampon* (peu naturel) | *N'oubliez pas le tampon* ; erreur : *N'en oubliez pas* → *N'oubliez pas*, le complément *au bureau* conservé |
| S3 PO — anagramme `cache` | indice contenait *cacher* | indice : *garder l'info pour soi* |
| S4 PE — erreur à trouver | correction trop courte, clauses coupées | une seule faute : *bruits* → *bruit* ; *tard le soir* conservé |

Contrôles gardés : *aussi* + adj. + *que* ; *vas-y* / *prends-en* ; *je le lui répète* ; *ne… jamais / plus / rien / personne* ; *à + le = au*.

| Lieu | Avant | Après |

## Contrôles communs aux 8 modules

- *Il faut* : jamais *je faut* / *tu faut* (hors phrases volontairement fautives).
- *Être* au futur : *je serai* (pas *je sera*) ; au conditionnel : *je serais*.
- *Faire* : *je ferai* / *vous ferez* (un r) ; *pouvoir* : *je pourrai* (deux r).
- PE : consigne **Imitez** (pas *Imitiez*) ; CE / PE à lire : *sans aller trop vite*.
- `audio_record` : enregistrement de l’apprenant, pas de TTS.
- Anagrammes : le mot-cible n’apparaît pas dans l’indice (y compris en sous-chaîne).
- Ordre des mots : aucun jeton virgule.
- QCM : 4 options, une seule correcte.
- SVG : 30 pictogrammes originaux par module, tous utilisés ; style géométrique terracotta / sarcelle + accent de module.
- 30 leçons × 10 exercices par module = **240 leçons, 2 400 exercices** ; `cefr_level = 'A2'` ; `published = false`.

Aucun dump `*_textes.txt` n’est versionné.
